# ASD-STE100 Issue 9 — Part 2: Recurring Errors & Word Replacements

This reference contains all items in the **List of Recurring Errors** (Part 2, Pages 2-0-17 & 2-0-18) and core vocabulary mappings from ASD-STE100 Issue 9.

## 2. Common Technical & Software Engineering Conversions

- Common Engineering Term | ASD-STE100 Issue 9 Approved Construction
- _execute / run (v)_ | **DO** _(v)_ (for example,. `Do the test`, `Do the script`)
- _verify / validate (v)_ | **MAKE SURE** _(v)_ / **CHECK** _(n)_ (for example,. `Make sure that the signature is valid`)
- _terminate / abort (v)_ | **STOP** _(v)_ (for example,. `Stop the process`)
- _initialize / instantiate (v)_ | **START** _(v)_ / **PREPARE** _(v)_ (for example,. `Start the server instance`)
- _modify / alter (v)_ | **CHANGE** _(v)_ (for example,. `Change the configuration`)
- _display / render (v)_ | **SHOW** _(v)_ (for example,. `Show the error modal`)
- _obtain / retrieve (v)_ | **GET** _(v)_ (for example,. `Get the token from storage`)
- _transmit / dispatch (v)_ | **SEND** _(v)_ / **TRANSMIT** _(v)_
- _prevent / mitigate (v)_ | **PREVENT** _(v)_
- _inspect / audit (v)_ | **EXAMINE** _(v)_ / **DO AN AUDIT OF**
