# ASD-STE100 Issue 9 — Part 2: Recurring Errors & Word Replacements

This reference contains all items in the **List of Recurring Errors** (Part 2, Pages 2-0-17 & 2-0-18) and core vocabulary mappings from ASD-STE100 Issue 9.

---

## 1. Complete Official List of Recurring Errors

The table below catalogs the most common non-STE words and their approved ASD-STE100 alternatives:

| Non-STE Word / Part of Speech | Approved STE Alternative / Construction   | Example Non-STE                     | Example STE Revision                                          |
| :---------------------------- | :---------------------------------------- | :---------------------------------- | :------------------------------------------------------------ |
| **acceptable** _(adj)_        | **PERMITTED** _(adj)_                     | "A value of 2 mm is acceptable."    | "A value of 2 mm is permitted."                               |
| **alternate** _(adj)_         | **ALTERNATIVE** _(adj)_                   | "Use the alternate route."          | "Use the alternative route."                                  |
| **any** _(adj)_               | _None or rephrase sentence_               | "Remove any loose screws."          | "Remove all loose screws." / "Remove loose screws."           |
| **avoid** _(v)_               | **PREVENT** _(v)_                         | "Avoid overheating."                | "Prevent overheating."                                        |
| **both** _(adj)_              | **THE TWO** _(TN)_                        | "Open both valves."                 | "Open the two valves."                                        |
| **check** _(v)_               | **CHECK** _(n)_ / **EXAMINE** _(v)_       | "Check the battery voltage."        | "Do a check of the battery voltage." / "Examine the battery." |
| **cover** _(v)_               | **COVER** _(TN / n)_ / **PUT A COVER ON** | "Cover the connector."              | "Put a protective cover on the connector."                    |
| **complete** _(adj)_          | **COMPLETED** _(adj)_                     | "The complete assembly..."          | "The completed assembly..."                                   |
| **damage** _(v)_              | **DAMAGE** _(n)_ / **CAUSE DAMAGE TO**    | "This may damage the unit."         | "This can cause damage to the unit."                          |
| **ensure** _(v)_              | **MAKE SURE** _(v)_                       | "Ensure the switch is OFF."         | "Make sure that the switch is in the OFF position."           |
| **fit** _(v)_                 | **INSTALL** _(v)_                         | "Fit the gasket into the groove."   | "Install the gasket in the groove."                           |
| **follow** _(v)_              | **OBEY** _(v)_                            | "Follow these instructions."        | "Obey these instructions."                                    |
| **further** _(adj/adv)_       | **MORE** _(adj/adv)_                      | "For further details..."            | "For more details..."                                         |
| **have to** _(v)_             | _Use imperative action verb_              | "You have to remove the nut."       | "Remove the nut."                                             |
| **however** _(adv)_           | **BUT** _(conj)_                          | "The light came on; however..."     | "The light came on, but..."                                   |
| **insert** _(v)_              | **PUT** _(v)_ / **INSTALL** _(v)_         | "Insert the pin into the slot."     | "Put the pin into the slot."                                  |
| **main** _(adj)_              | **PRIMARY** _(adj)_                       | "The main power supply..."          | "The primary power supply..."                                 |
| **may** _(v)_                 | **CAN** _(v)_                             | "This may cause an error."          | "This can cause an error."                                    |
| **need** _(v)_                | **NECESSARY** _(adj)_                     | "You need to clean the filter."     | "It is necessary to clean the filter."                        |
| **now** _(adv)_               | **AT THIS TIME**                          | "Now turn the dial."                | "At this time, turn the dial."                                |
| **old** _(adj)_               | **REMAINING** / **USED** / **EXPIRED**    | "Discard the old seal."             | "Discard the used seal."                                      |
| **over** _(prep)_             | **ABOVE** / **ON** / **ALONG**            | "Move the lever over the stop."     | "Move the lever above the stop."                              |
| **people** _(n)_              | **PERSON** _(n)_ / **PERSONNEL** _(n)_    | "Keep all people away."             | "Keep all personnel away."                                    |
| **perform** _(v)_             | **DO** _(v)_                              | "Perform the diagnostic test."      | "Do the diagnostic test."                                     |
| **portion** _(n)_             | **PART** _(n)_                            | "Clean the top portion."            | "Clean the top part."                                         |
| **press** _(v)_               | **PUSH** _(v)_                            | "Press the red button."             | "Push the red button."                                        |
| **reach** _(v)_               | **GET** _(v)_                             | "Until values reach 100."           | "Until values get to 100."                                    |
| **repeat** _(v)_              | **DO ... AGAIN**                          | "Repeat steps 1 to 3."              | "Do steps 1 to 3 again."                                      |
| **required** _(v)_            | **NECESSARY** _(adj)_                     | "Tools required for this job..."    | "Tools that are necessary for this job..."                    |
| **rotate** _(v)_              | **TURN** _(v)_                            | "Rotate the shaft clockwise."       | "Turn the shaft clockwise."                                   |
| **secure** _(v)_              | **ATTACH** _(v)_ / **SAFETY** _(v)_       | "Secure the bracket with bolts."    | "Attach the bracket with bolts."                              |
| **shall** _(v)_               | **MUST** _(v)_                            | "The operator shall verify..."      | "The operator must make sure that..."                         |
| **should** _(v)_              | **MUST** _(v)_                            | "The valve should be closed."       | "The valve must be closed."                                   |
| **since** _(conj)_            | **BECAUSE** _(conj)_                      | "Since voltage is low..."           | "Because voltage is low..."                                   |
| **test** _(v)_                | **TEST** _(n)_                            | "Test the sensor response."         | "Do a test of the sensor response."                           |

## 2. Common Technical & Software Engineering Conversions

| Common Engineering Term        | ASD-STE100 Issue 9 Approved Construction                                             |
| :----------------------------- | :----------------------------------------------------------------------------------- |
| _execute / run (v)_            | **DO** _(v)_ (e.g. "Do the test", "Do the script")                                   |
| _verify / validate (v)_        | **MAKE SURE** _(v)_ / **CHECK** _(n)_ (e.g. "Make sure that the signature is valid") |
| _terminate / abort (v)_        | **STOP** _(v)_ (e.g. "Stop the process")                                             |
| _initialize / instantiate (v)_ | **START** _(v)_ / **PREPARE** _(v)_ (e.g. "Start the server instance")               |
| _modify / alter (v)_           | **CHANGE** _(v)_ (e.g. "Change the configuration")                                   |
| _display / render (v)_         | **SHOW** _(v)_ (e.g. "Show the error modal")                                         |
| _obtain / retrieve (v)_        | **GET** _(v)_ (e.g. "Get the token from storage")                                    |
| _transmit / dispatch (v)_      | **SEND** _(v)_ / **TRANSMIT** _(v)_                                                  |
| _prevent / mitigate (v)_       | **PREVENT** _(v)_                                                                    |
| _inspect / audit (v)_          | **EXAMINE** _(v)_ / **DO AN AUDIT OF**                                               |
